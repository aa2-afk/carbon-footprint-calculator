# Carbon Footprint Calculator

A responsive school web-development project built with HTML, CSS, and Bootstrap 5.

## Files
- `index.html` — page structure and content
- `style.css` — custom page styling

## Run locally
Open `index.html` in a web browser. An internet connection is needed for Bootstrap and the remote landscape image.

## Publish with GitHub Pages
1. Create a **public** repository on GitHub.
2. Upload `index.html` and `style.css` to the repository's root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown in the Pages settings.

The Calculate link currently jumps to a short information note on this page. If your teacher expects a working calculation form, add that functionality as a separate requirement.
